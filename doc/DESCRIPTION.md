Stoat (formerly Revolt) is an open-source, user-first community chat platform: servers with text and voice channels, direct messages and groups, roles and permissions, custom emojis, bots and file sharing.

### Features

- Servers, categories, text and voice channels
- Voice, camera and screen sharing (LiveKit)
- Direct messages and group chats
- Roles, permissions, moderation and audit logs
- Bots and webhooks API
- Web client usable as a PWA
